# StreetSmart Insurance - Video Walkthroughs & Policy Entry (APE) Catalog

Master repository of official StreetSmart Loom video walkthroughs and standard operating procedures (SOP) across all Lines of Business (LOBs). Extracted directly from the **Policies-Application/Policy Entry (APE)** master database.

---

## 1. Commercial Lines Video Directory

| Line of Business | Official Loom / Video Walkthrough | Critical Verification & Entry Rules |
| :--- | :--- | :--- |
| **Commercial Auto Liability** | [Loom: Comm Auto Walkthrough](https://www.loom.com/share/0f1a1709f5264e15939b0c048cea6028)<br>[Drive: Video Recording](https://docs.google.com/videos/d/1i3PEORwuzPMKRAaF1qsqQ58y2wiH7YnValEzgr05GrQ/edit?scene=id.p) | Match dec page (addresses, business type). For locations, add building details and verify coverage symbols/limits (CSL, BI). For vehicles, enter VIN, type, garaging address, comp/coll deductibles, and review driver exclusions. Enter banks/mortgagees with correct vehicle associations. |
| **Business Owner Policy (BOP)** | [Loom: BOP Walkthrough](https://www.loom.com/share/dc0d74328429498183e342992fcb4aa7) | Match dec page (insured name, address). Most BOPs are Special Form. Verify location building (check with agent if needed). Review coverages, limits, deductibles. Enter premises info with location. Add class codes, rating info, banks/mortgagees (additional interest), and policy contacts. |
| **Commercial Package** | [Loom: Package Walkthrough](https://www.loom.com/share/50e461126ea5412fa87289ab06cd3469)<br>[EZLynx Misc LOB Article](https://ezlynxsupport.freshdesk.com/support/solutions/articles/8000113392-management-system-misc-lob-added-to-commercial-package) | Convert commercial package apps to "Package" in EZLynx. Ensure data matches dec page. GL Package: claims basis, limits/deductibles (Per Policy if unclear), ancillary coverages to GL class code section. Property Package: select location, enter all subjects of insurance. Include class codes, mortgagees, and policy contacts. |
| **Commercial Property** | [Loom: Commercial Property](https://www.loom.com/share/48d74e22a77a481d8268fe30c6947376) | Match dec page exactly (insured, address, location). Insured property location must match decs. Enter subjects of insurance (amount, coinsurance, etc.) with building descriptions. Include additional named insureds and mortgagees. All locations must have buildings listed. |
| **Commercial Umbrella** | [Loom: Commercial Umbrella](https://www.loom.com/share/a491c3ab97dd4f33b3a3aa8e077f230c) | Match dec page limits. Verify underlying policies in system and on file. Match transaction type (Claims Made / Occurrence) and coverage amount. Include deductibles / retained limits, retro dates, First Dollar Defense. Pro Tip: Keep underlying policy copies on file to prevent gaps. |
| **General Liability** | [Loom: General Liability](https://www.loom.com/share/b507be54b3df45e3afcb95f37fa39015) | Match dec page (mailing address, location w/ buildings). Select GL and claims basis (made/occurrence). Review limits/deductibles/General Aggregate (Per Policy if unclear). Check endorsements (blanket AI). Enter class codes. Subcontractors? Answer "Yes" and add details. Include banks/mortgagees and contacts. |
| **Workers' Compensation** | [Loom: Workers Comp](https://www.loom.com/share/0b7a9f616b17456a84a4e4db2153d289) | Match declarations (insured, address, location - buildings required). Owner included/excluded? Check PP1B Form. Class codes & contacts: enter all codes & add contacts. Ensure class codes match locations, coverages & owner info. State coverage: select covered states (deselect excluded). |
| **Garage & Dealers Policy** | [Loom: Garage & Dealers](https://www.loom.com/share/2e53898e240a4036a0c8c63c2b796a9e) | Match decs (insured, address, location w/ buildings). Select "Garage & Dealers". Operations: Dealer (Class I & II employees) or Non-Dealer (premises & ops). Coverages: Auto/Premises/Combined. Review limits/deductibles, vehicle schedule, driver data (required), and mortgagees. |
| **Inland Marine (Commercial)** | [Loom: Inland Marine](https://www.loom.com/share/421ff2e1099b4073b346d8a8e8fde402) | Match decs (insured, address, location w/ buildings). Enter all equipment info. Verify coverages (included/excluded) against policy document. |
| **Inland Marine Builders Risk** | SOP Reference | Match decs (insured, address, project location). Verify total completed value, construction term, and project description. Review coverages (hard costs, soft costs, business income), flood, earthquake, transit. Confirm 'permission to occupy' status. Include owners, GCs, lenders. |
| **Crime** | [Loom: Crime Walkthrough](https://www.loom.com/share/69a0c734285c466da1c11f9fcf889870) | Match policy details (company, number, dates, premium). Select "Crime". In EZLynx Crime, confirm buildings/locations match before saving. Verify coverage basis (most Discovery). Enter coverage types (Forgery, Money/Securities). Fill out underwriting tabs (controls, audits, employees, claims). |
| **Errors & Omissions (E&O)** | [Loom: E&O Walkthrough](https://www.loom.com/share/5bc7644048f34c02a74ef8d4812c62bc) | Match decs. Select "E&O" (not professional liability). Coverages: Limits, Retention, Separate Defense Cost (Y/N). Financials: Revenue (current & 3Y), product/service list w/ %, 5 largest jobs past 3Y. Underwriting: General & claims info. |
| **Cyber Liability / D&O** | Standard SOP | Cannot input details of coverage directly in EZLynx grid; put limit and coverage description in Description Box for now. |

## 2. Personal Lines Video Directory

| Line of Business | Official Loom / Video Walkthrough | Critical Verification & Entry Rules |
| :--- | :--- | :--- |
| **Personal Auto** | [Loom: Personal Auto](https://www.loom.com/share/efbd57168ba240a39f8823c614e6da1b) | Ensure EZLynx data matches Personal Auto decs page: enter driver details, check coverage types and limits, enter vehicle info (VIN, mileage), and accidents/violations. Include additional coverage and lienholder info. |
| **Homeowners (HO-3/HO-5)** | [Loom: Homeowners](https://www.loom.com/share/f05774171d434032811b2e3eb9fd5734) | Ensure EZLynx data matches HO dec page. Verify named insureds, address, and property location. Match coverages and deductibles (avoid Full Value Replacement Cost). Enter mortgagees with "Send Bill" if applicable. |
| **Condominium (HO-6)** | [Loom: Condominium](https://www.loom.com/share/d70cdb56e4b54d6fb8e957ccbc57c012) | Verify unit interior dwelling limits (Coverage A), personal property (Coverage C), loss assessment, and association master policy deductibles. |
| **Dwelling Fire (DP-1/DP-3)** | SOP Reference | Match dec page: enter all insured people and mailing address. Insured property location and mailing address are almost always different. Check underwriting tab for lienholders. |
| **Personal Umbrella** | [Loom: Personal Umbrella](https://www.loom.com/share/0b0aca4db8f34f839872edc6949c25ba) | Match decs (coverages, deductibles, insureds). Enter vehicles and drivers. Maintain copies of underlying policies (Auto & Home) on file to avoid gaps. |
| **Inland Marine (Personal)** | [Loom: Personal Inland Marine](https://www.loom.com/share/8e6e52245c744b3189b6e73ef0eb6cb3) | Match decs (scheduled items, values, jewelry/fine arts). Add specific location schedule (schedule # differs from item #). Indicate whether scheduled property is stored in vault (Yes/No). Include lienholders. |
| **Mobile Home** | SOP Reference | Ensure EZLynx matches dec page: driver details, coverage types/limits, vehicle/unit info, additional coverage, and lienholders. |
| **Motorcycle** | SOP Reference | Match motorcycle policy decs: driver details, coverage limits, vehicle details (VIN), additional equipment coverage, and lienholders. |
| **Watercraft (Boat)** | SOP Reference | Match boat/yacht dec page: hull value, trailer, motor HP, P&I liability, and navigation waters warranty. |
| **Life Insurance** | SOP Reference | Put Death Benefit coverage and policy details in EZLynx Description Box. |
